# 우리집 준비노트

신혼집 가전·가구 통합 관리용 로컬 웹앱입니다.

## 실행 방법

가장 간단한 방법:

1. 이 폴더에서 터미널을 엽니다.
2. `python -m http.server 8080` 실행
3. 브라우저에서 `http://localhost:8080` 접속

별도 설치 과정은 없습니다. `index.html`, `styles.css`, `app.js`, `assets/home-floorplan.png`만으로 동작합니다.

## 데이터 저장

- 브라우저 LocalStorage
- 저장 키: `newlywedHomeManager:v1`
- `schemaVersion: 1`
- 새로고침/브라우저 재실행 후에도 같은 브라우저에서 유지
- 설정에서 JSON 전체 백업/복구 가능
- 제품 목록 CSV 내보내기 지원

## 구현된 핵심 기능

- 대시보드: 전체 예산, 실제 지출, 남은 예산, 체감가, 절약/초과, 구매 진행률, 입주 D-Day
- 제품 CRUD: 가전/가구/생활용품, 가격, 구매상태, 우선순위, 결제/분담, 크기, 설치상태, 이미지, 메모
- 자동 계산: 예상가/실구매가/체감가/절약·초과
- 부부 비용 분담 계산
- 제품 검색/필터
- 제품 후보 최대 5개 비교
- 견적 등록/수정/삭제 및 체감가 비교
- 방별 예상/실제 지출 및 준비율
- 체크리스트와 진행률
- 구매/배송/설치 일정
- 위시리스트
- 예산 분석
- 실제 원본 평면도 Base Layer + 제품 Overlay Layer
- 평면도 제품 Drag & Drop, 90도 회전, 배치 위치 저장
- JSON 전체 백업/복구, CSV 내보내기, 2단계 초기화
- 모바일 하단 네비게이션 및 플로팅 추가 버튼

## 현재 버전의 제한

- 로그인/클라우드 동기화/두 사람 실시간 공동편집은 미구현
- 제품 가격 히스토리, 영수증/보증서/AS 기록, 여러 평면도 버전은 미구현
- 평면도 스케일은 등록된 제품 크기와 5800mm 기준 폭을 이용한 근사 Overlay 크기이며, 실제 설치 가능 판정은 자동 확정하지 않음
- 제품 이미지 업로드는 LocalStorage 용량 제한 때문에 작은 이미지 권장

## 향후 수정 시 주요 파일

- `app.js`: 데이터 모델, 계산, 화면 렌더링, CRUD, 로컬 저장, 평면도 배치
- `styles.css`: 전체 디자인/반응형 UI
- `assets/home-floorplan.png`: 원본 평면도. 직접 수정하지 말고 Base Layer로 유지
- `index.html`: 앱 진입점

### 추가 구현

- 제품 이미지 URL 또는 직접 업로드 지원
- 사용자 카테고리 추가/삭제
- 첫 실행 예시 데이터 명확한 배지 표시 및 일괄 삭제
